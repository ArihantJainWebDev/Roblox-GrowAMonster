# Original geometry sources

original-world-assets.obj and .mtl are generated from the project-authored tools/art/BuildWorldAssetStudy.luau source. They contain the original fountain, cliff and broadleaf mesh studies, not third-party Creator Store models. Coordinates are original study space in Roblox studs. Objects and materials are separated by name; no external textures are referenced. Use an OBJ-capable modeler/importer to inspect them. Studio supports the equivalent generator through the connected Edit tools.

These are unaccepted review assets, not production-ready collision/animation/UV assets. Do not replace gameplay with these automatically. The world production quality gates still apply.
