# Phase 8 — Release Readiness and Optional Cosmetics

**Status:** Planned; depends on complete free core progression.

## Goal

Prepare a stable first release; consider cosmetic purchases only after the game is complete without them.

## Planned work

- Exercise save/load, migrations, throttling, disconnects, and rejoin behavior.
- Check performance and controls on representative touch and desktop devices.
- Review platform safety, accessibility, moderation, and purchase flows.
- If approved, add clearly priced direct-purchase cosmetics with server-verified grants.
- Prepare player-facing description, onboarding, support expectations, and rollback plan.

## Verification and exit checks

- New and returning players can complete the core loop and retain valid progress.
- No paid item grants growth, evolution, competitive power, or required food.
- Purchase processing is verified by Roblox on the server and grants cannot duplicate.
- Known issues, content scope, and support behavior are documented before publishing.
